# ACME Salary Management

Web software for an HR manager to manage salary data for a 10,000 person,
multi-country organization and answer questions about how the org pays people.

- `server/` - NestJS API with Prisma and SQLite
- `web/` - Next.js UI
- `docs/` - requirements, design notes, architecture, AI usage log, trade-offs, performance

Full setup instructions land with the first working version.
